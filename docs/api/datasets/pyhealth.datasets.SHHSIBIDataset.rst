pyhealth.datasets.SHHSIBIDataset
===================================

The SHHS IBI dataset extracts ECG-derived IBI signals from the Sleep Heart Health Study for wearable sleep staging. Refer to `doc <https://sleepdata.org/datasets/shhs>`_ for more information.
